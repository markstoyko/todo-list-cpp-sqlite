# Менеджер задач (Todo List)

Консольное приложение на C++ для ведения списка задач с сохранением данных в базе SQLite.

## Возможности

- Добавление задач с названием и описанием
- Просмотр всех задач в табличном виде
- Фильтрация по статусу: активные / выполненные
- Отметка задачи как выполненной
- Удаление задачи по идентификатору
- Статистика прогресса (общее количество, активные, выполненные)

## Структура данных

- База данных: SQLite (локальный файл `tasks.db`)
- Таблица `tasks` с полями:
  - `id` – уникальный идентификатор (автоинкремент)
  - `title` – название задачи
  - `description` – описание
  - `is_done` – статус (0 / 1)
  - `created_at` – дата и время создания (автоматически)

## Технологии

- Язык: C++17
- База данных: SQLite3 (амальгама, файлы `sqlite3.c` и `sqlite3.h` в проекте)
- Среда разработки: Visual Studio 2022
- Стандартная библиотека: STL (iostream, string, vector, iomanip)

## Сборка и запуск

1. Откройте файл решения `.sln` в Visual Studio
2. Убедитесь, что файлы `sqlite3.c` и `sqlite3.h` находятся в папке проекта
3. Выберите конфигурацию Release
4. Нажмите F5 для сборки и запуска

Либо скомпилируйте вручную (при наличии установленного SQLite):

```bash
g++ -std=c++17 main.cpp database.cpp task.cpp -lsqlite3 -o todo.exe
./todo.exe
